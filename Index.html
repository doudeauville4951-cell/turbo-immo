Comment obtenir une config Firebase ? (tutoriel)
1. Allez sur console.firebase.google.com
2. Cliquez "Ajouter un projet" → nommez-le (ex: turbo-immo) → Continuer
3. Dans le projet, cliquez l'icône </> (Web) → enregistrez l'app
4. Copiez l'objet firebaseConfig et collez-le ci-dessous
5. Dans le menu gauche → Build → Realtime Database → Créer une base → Mode test
6. Choisissez un Workspace ID (un mot simple partagé entre tous les utilisateurs, ex: turbo2024)

Chaque utilisateur doit saisir la même config + le même Workspace ID.
Un mot simple sans espace. Tous ceux qui saisissent le même ID partagent les données.
